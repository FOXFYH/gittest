## 一、先搞清「真身」在哪（最重要）

- **真身 = 本地 Python**：`贴吧核心.py`（数据层）+ `贴吧服务端.py`（本机投递口，唯一写入方）。
- **网页只是门面**：`贴吧网页.html` 用 `POST /api` 找 **本机服务端**，默认端口 **19885**。
- ⚠ 所以 GitHub Pages 上那份 `TIEBA/贴吧网页.html` **不是能直接跑的网站**：
  它的 `/api` 会打到 `github.io` 去，连不上 → 页面打开是空的。
  云端这些文件是 **备份 / 分发 / 查看源码** 用；真要看贴吧，开本机或局域网门面：
  - 本机：`http://127.0.0.1:19885/`
  - 手机（同一 WiFi）：`http://<本机局域网IP>:19885/`（服务端默认绑 `0.0.0.0`，启动横幅会打印这个地址）

## 四、怎么部署（推荐：一次性整目录提交）

`ul-dir` 是**按「给的目录内部相对路径」上传**的（不会带目录名），所以不能直接把
项目目录丢给它——否则会散到仓库根。正确姿势是先搭一个**暂存目录**，里面放 `TIEBA\`：

```powershell
# 1) 搭暂存目录（示例路径，可换）
$暂 = "C:\Temp\tieba_deploy"
Remove-Item -Recurse -Force $暂 -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force -Path "$暂\TIEBA" | Out-Null

# 2) 把要部署的文件复制进 TIEBA 子目录
$源 = "d:\网络硬盘\wps云盘\脚本备份\工作台\贴吧型派单系统"
Copy-Item "$源\贴吧核心.py","$源\贴吧服务端.py","$源\贴吧MCP服务.py","$源\贴吧CLI.py","$源\贴吧网页.html","$源\部署必看.md" "$暂\TIEBA\"

# 3) 先试运行（看清是 新增 TIEBA/xxx，再正式传）
py "D:\网络硬盘\wps云盘\脚本备份\工作台\开发资源包\github助手\github助手含CLI.py" ul-dir FOXFYH/gittest $暂 --dry

# 4) 正式上传（一次提交；不加 --delete，绝不动仓库里别的文件）
py "D:\网络硬盘\wps云盘\脚本备份\工作台\开发资源包\github助手\github助手含CLI.py" ul-dir FOXFYH/gittest $暂
```

> ⚠ **千万别对 gittest 根目录用 `ul-dir ... --delete`**，会把仓库里其它项目文件全删了。

只想更新单个文件时用 `ul-file`（远端路径可带子目录）：

```powershell
py "...\github助手含CLI.py" ul-file FOXFYH/gittest "$源\贴吧网页.html" "TIEBA/贴吧网页.html"
```

其它常用命令：

```powershell
py "...\github助手含CLI.py" files    FOXFYH/gittest              # 列文件树（相对路径 + 字节数）
py "...\github助手含CLI.py" dl-file  FOXFYH/gittest "TIEBA/贴吧网页.html" -o "C:\Temp\拉回.html"
py "...\github助手含CLI.py" url      FOXFYH/gittest "TIEBA/贴吧网页.html"   # 拼 Pages 地址
```

## 五、版本号规则（不 bump = 用户看不出改动）

- **网页版本号**：`贴吧网页.html` 里的 `const VER='0.1.1';`（每次改网页 `+0.01`）
- **后端模块版本**：各 `.py` 顶部的 `模块版本 = '0.1.0'`
- 改了就 bump，再部署；部署后把 commit 哈希记到本文件末尾「部署记录」

## 六、蹲守验证（必须，传完不许就走）

1. `dl-file` 把云端文件拉回临时位置；
2. 与本地文件 `fc /b` 逐字节比对（或比 SHA）：**必须零差异**；
3. 实测线上 URL：HTTP **200**，且页面里能搜到**当前版本号**（`VER='0.1.x'`）；
   （浏览器/WebFetch 有缓存，第一次可能还是旧版——以 `dl-file` 比对为准）
4. 把提交 URL/哈希补进「部署记录」。

## 七、踩坑点（前面用命换的）

- **PowerShell 5.x 不支持 `&&`**，命令串联用分号 `;`；含中文/空格的路径**必须加双引号**。
- **GUI 与 CLI 可以并行，但写操作（上传/删除）不要同时打同一仓库**，会互相顶提交，排队做。
- 网络偶发超时、退出码 `1` 属正常，**直接重试**（命令幂等，按内容指纹跳过，不会重复提交）。
- **改动 `贴吧服务端.py` 前先查 WPS 云同步看护**，避免被回档：
  ```powershell
  py "D:\网络硬盘\wps云盘\脚本备份\工作台\开发资源包\WPS云同步开关\WPS云同步开关含CLI.pyw" guard
  ```
  返回 `guard_active=true` 且看护资源里含你要改的文件 → 避开约 1 分钟。平时不必手动 off/on（已被服务端联动接管）。
- 中文文件名在 URL 里会被百分号编码，别自己手拼地址，用 `url` 命令。
- 改完网页记得**同步改本地项目目录那一份**，别只改暂存目录。
