# AI 工作台

> 代码就在 `工作台\AI大模型工具\TRAE远程控制2.0\公共设施\AI工作台\`；发布到 GitHub 时目录名统一用 **`AI工作台`**。

一句话：一台 Windows 上的「总管驾驶舱」——TRAE 健不健康、手上有哪些人、任务卡走到哪一步、人类原话怎么说的，一个窗口看全，手机上也能看。
纯 Python 标准库，无第三方依赖，双击即用，默认一个字节都不出本机。

## 四个分页

| 分页 | 看什么 | 数据从哪来 |
|---|---|---|
| P1 TRAE 健康 | 进程在不在、调试端口通不通、当前模式（Code / 其他）、积分余量 | 本机进程 + 本地调试端口 |
| P2 员工 | 谁在岗、终身号、手上几条任务、最近一次冒泡时间 | 员工名册 + 会话账本 |
| P3 任务卡 | 待办 / 在做 / 待验收 / 已完成；谁负责、卡在哪 | `任务卡.json`（本地文件） |
| P4 人类原话 | 每句原话一字不改留档，配「成单 / 单号 / 落实」三个标记 | 原话流水账目录 |

## 怎么跑

```bat
python 总管面板.pyw              :: 正常：开窗口 + 起网页服务
python 总管面板.pyw --headless   :: 只起网页服务，不开窗（适合挂后台）
python 总管面板.pyw --no-web     :: 只开窗口，不起网页服务
python 总管面板.pyw --自测       :: 跑一遍自检，结果打屏
```

窗口一关网页服务就停；要长期挂机请用 `--headless`。

## 网页版怎么连

- 本机：浏览器开 `http://127.0.0.1:19900`
- 公网：把 `网页端源文件/` 推到 GitHub 并开 Pages，访问 `https://<账号>.github.io/<仓库>/`
- 公网必须带令牌：网址后面加 `?令牌=xxxx`，不带令牌只给看、不给动
- 首次登录需输入频道号（见随附说明）；频道号与首次密码是凭据，**不入库、不写在本文件里**
- ⚠ Pages 上那份只是界面和备份，**真数据只在本机**，要连 `127.0.0.1:19900` 才是能用的面板

## 令牌怎么生成（仅备用部署方式需要）

如果用 GitHub 助手 CLI 推送，本节可以跳过。

GitHub → 右上头像 → Settings → Developer settings → Personal access tokens →
Tokens (classic) → Generate new token，勾 **repo**，生成后复制 `ghp_` 开头那串。
只显示一次，及时存进密码管理或本机 `遥控令牌.txt`（该文件已被 `.gitignore` 挡住）。

## 安全说明

- 默认只绑 `127.0.0.1`，同一个局域网的其他机器都连不上
- `--bind 0.0.0.0` 必须同时给 `--令牌`，缺令牌启动直接报错退出
- 公网来的动作（改任务卡、推命令）全部落进 `动作队列.jsonl`，谁在几点干了什么可倒查
- `配置.json` / `状态.json` / `员工名册.json` 只在本机，永远不进仓库
- 上传前强制跑 `部署\脱敏审计.py`，不是 CLEAN 一律拒绝上传

## 目录结构

```
AI工作台\                 （本目录）
├── 总管面板.pyw          # 主入口（窗口 + 网页 + 参数）
├── 公共.py               # 路径寻址 / 配置 / 原子写 / 文件锁 / 日志
├── 核心.py               # 采集与调度
├── 网页服务.py           # 本地 HTTP 服务
├── 网页端源文件\          # 静态网页；Pages 发布的就是这个目录
├── 手册\                  # 本机作业手册（不进仓库；没有这个目录时程序显示「本机无手册」）
├── 部署\                  # 一键推 GitHub（deploy_github.py）+ 脱敏审计
├── 状态.json             # 运行时状态（不进仓库）
└── 任务卡.json           # 任务卡数据（不进仓库）
```

运行期数据统一落 `D:\使用痕迹\AI工作台\`（本机固定落点，仓库里只有代码）。
